# Aset

Folder ini untuk aset buatan tim.

- `art/` untuk ilustrasi 2D dari 2D Artist, misalnya foto Raka & Ibu, meja kerja, peta, dan latar ending.
- `audio/` untuk SFX dan musik dari Sound Designer, misalnya dering HP, klik, dan ambient hujan.

Aturan Gimersia Inspire 2026:

- **AI tidak boleh dipakai untuk membuat aset visual.**
- Aset dari asset store/library boleh dipakai, tapi **sumbernya wajib dicatat** di [docs/CREDITS.md](../../docs/CREDITS.md) dan di-declare di form submission.

Saat ini gim memakai placeholder: kotak bertulisan `[ilustrasi ...]`, ikon emoji sistem, dan SFX sintesis Web Audio di `js/audio.js`.
